# Android UI Polish

A Claude Skill that helps improve the quality of native Android user interfaces by reviewing UI, animations, haptic feedback, visual consistency, and overall user experience.

## What it does

This Skill reviews an Android screen and suggests practical improvements for:

- UI animations
- Transitions
- Micro-interactions
- Haptic feedback
- Material Design consistency
- Empty states
- Error states
- Icons
- Accessibility
- Visual hierarchy

The goal is to transform a functional interface into a polished, production-ready Android experience.

---

## When to use

Use this Skill when you want Claude to:

- Review an Android screen.
- Suggest UI improvements.
- Improve UX.
- Polish an existing interface.
- Make an app feel more premium.
