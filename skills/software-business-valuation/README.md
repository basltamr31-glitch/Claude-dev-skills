# Software Business Valuation & Exit Strategy

A Claude Skill for valuing software products and businesses and evaluating their readiness for a potential exit.

This Skill acts as a software M&A advisor, combining software valuation analysis, technical due diligence, buyer analysis, product strategy, and exit planning into one structured workflow.

## What it does

The Skill helps evaluate:

- Fair Market Value (FMV)
- Recommended Asking Price
- Expected Transaction Price
- Fast-Sale Price
- Sellability Score
- Exit Readiness Score
- Valuation Confidence
- Potential buyers and buyer types
- Technical and business due-diligence gaps
- Roadmap items based on their potential exit value
- Sell-now vs. build-more decisions

## Key principles

The Skill keeps different concepts separate:

- Market value
- Development cost
- Asking price
- Expected transaction price
- Fast-sale price

It also avoids inventing missing business data. Material information is explicitly classified as known, estimated, inferred, unknown, or requiring verification.

## Best suited for

Use this Skill when evaluating:

- SaaS products
- Micro-SaaS businesses
- Mobile applications
- Marketplaces
- AI products
- API businesses
- Software products and codebases

It can also help determine what should be built before an exit and which roadmap items are unlikely to create meaningful additional exit value.

## Output

The Skill produces a structured valuation and exit analysis based on the available evidence, including valuation ranges, confidence levels, buyer analysis, due-diligence gaps, roadmap recommendations, and a clear sell-vs-build verdict.
