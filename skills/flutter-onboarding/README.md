# Flutter Onboarding

A Claude Skill for building modern, production-ready onboarding experiences in Flutter.

This Skill guides Claude through creating scalable onboarding flows using Flutter best practices. It focuses on clean architecture, reusable components, responsive layouts, smooth animations, and a data-driven approach instead of hardcoded screens.

## What it does

This Skill helps developers:

- Build onboarding flows with `PageView.builder`
- Create reusable and scalable onboarding screens
- Implement animated page indicators
- Support Lottie animations
- Persist onboarding completion using `shared_preferences`
- Set up first-launch navigation
- Follow production-ready Flutter architecture
- Handle common onboarding issues and edge cases

## When to use

Use this Skill when you want to:

- Build a new onboarding experience
- Refactor an existing onboarding flow
- Improve onboarding architecture
- Add a first-launch experience to your application
- Generate a maintainable and reusable onboarding implementation
